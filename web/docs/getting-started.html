Getting started.

Build the native app, choose an interface, and find a setup path for a package manager.

DOCUMENTATION
OverviewGetting startedManager guideLocal pluginsSafety & privacy

1. Build and run

Install the Rust toolchain using rustup, then run these commands from the project folder:

cargo build --release
cargo run

Running cargo run opens the native desktop GUI. For repeated use, build the release executable with cargo build --release.

2. Use the desktop GUI

  1. Search or browse the managers available for your current operating system.
  2. Select a manager to read its description, prerequisites, and official setup links.
  3. Choose Download installer when a downloadable installer is configured.
  4. Choose Install / set up. The app asks you to confirm before it runs an installer.
  5. Use Open official page to view the manager’s setup instructions in your browser.

Download first when needed. Downloaded installers must exist locally before the app can run them. A command-based installer or local plugin may not need a separate download.

3. Use the terminal UI

Start the keyboard-driven interface with:

cargo run -- --tui
KeyAction
↑ / ↓ or j / kSelect a manager
dDownload a standalone installer, when available
iInstall or set up; confirm downloaded installers when prompted
oOpen the official setup page
q / EscQuit
y / nConfirm or cancel a pending install

4. Use the command line

List managers available on this system or work with one manager by its registry ID:

# List managers available on this operating system
cargo run -- --list

# Download the configured installer for a manager
cargo run -- --download brew

# Install after an interactive confirmation
cargo run -- --install brew

# Skip the prompt for this explicitly selected manager
cargo run -- --install brew --yes

Replace brew with an ID from the manager list. --yes applies to the one explicitly named installation; it does not install apps from a package-manager catalog.

Registry and plugin paths

Defaults can be overridden with flags or environment variables:

PurposeFlagEnvironment variable
Manager registry--sources-file PATHAPP_STORE_SOURCES
Plugin directory--plugins-dir DIRAPP_STORE_PLUGINS
Installer downloads—APP_STORE_DOWNLOADS

Use Local installer plugins to learn how to add a custom entry.

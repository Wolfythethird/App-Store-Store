Why manager availability differs

The app filters manager entries by the operating system and architecture supported by the registry profile. A tool that cannot be set up on the current system is hidden rather than offered as an install action. The visible list can therefore differ between Windows, macOS, Linux, and other supported systems.

The registry is maintained in the project-root sources.list YAML file. Each entry can declare supported operating systems, prerequisites, installation checks, and installer profiles.

Setup methods

Label or behaviorWhat it means
Download availableAn official HTTPS installer can be downloaded for this platform. Download it before running it.
Command installerThe setup uses a local command already installed on the computer. Declared prerequisites are checked first.
System managedThe tool is supplied by the OS or distribution. Follow its official setup page; the app does not replace your OS package manager.
Runtime requiredThe manager is bundled with or depends on a language/runtime. Install that prerequisite separately.
Setup guideNo configured installer is available here. Open the official instructions to continue manually.
Local pluginA custom local manifest supplies a script or installer profile. See the plugin guide.

Prerequisites are not installed for you

Some entries represent a language’s built-in package tool or an ecosystem rather than a standalone app. Examples include npm with Node.js, Cargo with Rust, Go modules with Go, and Swift Package Manager with Swift. Other install commands require tools such as Homebrew, RubyGems, or Coursier.

The selected-manager details show declared prerequisites. If a required executable cannot be found, the app reports which prerequisite is missing and stops instead of silently installing it.

Install the language or toolchain first. App Store Store focuses on the manager selected by you; it does not bootstrap unrelated runtimes behind the scenes.

Installation status and loading

The desktop and terminal interfaces check installed status for visible entries as they are shown. This avoids performing status checks for every registry item when opening the interface. Detection uses the configured executable check; it is a convenient signal, not a complete audit of every installation location.

System managers may already be part of the operating system. Their setup page explains the supported path for that OS or distribution.

Browse examples

The website’s manager cards are examples, not a live inventory from the app. For the actual current machine list, run:

cargo run -- --list

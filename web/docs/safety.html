Safety & privacy.

Know what the app downloads and runs before using an installer or custom plugin.

Installers can change your system

Package-manager installers can modify system files, add executables, update shell configuration, or fetch and run more code. The app asks for confirmation before running a configured installer. Read the prompt and the project’s official installation instructions before you agree.

Review before running. A confirmation prompt helps prevent accidental installs; it does not verify that an installer is benign or undo its changes.

What downloads do

Configured installer downloads use HTTPS, follow a limited number of redirects, and are rejected if a redirect leaves HTTPS. Downloads are limited to 50 MiB. If a registry profile provides a SHA-256 digest, the app verifies it before saving the installer.

Checksums are only meaningful when the expected digest comes from a source you trust. A profile without a digest does not receive checksum verification.

What runs locally

  • Official installer scripts are run with the current user’s permissions after confirmation.
  • Local plugin scripts are also run with the current user’s permissions and are not sandboxed.
  • Command-based profiles invoke the configured local executable with fixed registry arguments after checking declared prerequisites.
  • Prerequisites are checked, not installed automatically.

Only use installers from official sources and plugins you have reviewed. For local plugins, path restrictions keep the script file inside the plugin directory, but cannot make the script’s actions safe.

Application scope

App Store Store manages package-manager setup. It does not install apps from package catalogs or perform general application searches. The manager list is loaded from the local YAML registry and any configured local plugin manifests.

This website is a static product and documentation site. Its manager examples are illustrative; installing or setting up software requires the native Rust application.

Smart App Control and platform protections

If an operating system blocks an executable or installer, do not disable platform protections or run certificate scripts to bypass the block. Check the publisher and official project instructions, obtain software from a trusted source, and follow the operating system’s supported review or allow-listing process if appropriate.
